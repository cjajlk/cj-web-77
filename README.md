# CJ Web 77

Projet de site vitrine pour artisans, commerçants et indépendants à Melun et en Seine-et-Marne.

## Arborescence

- `index.html` : page d’accueil
- `legal.html` : mentions légales provisoires
- `privacy.html` : politique de confidentialité provisoire
- `404.html` : page d’erreur 404
- `robots.txt` : directives pour les moteurs de recherche
- `sitemap.xml` : plan du site avec URLs provisoires

## Objectifs

- Utiliser une structure HTML5 sémantique
- Préparer un formulaire accessible et modifiable
- Présenter des maquettes fictives sans contenu réel
- Maintenir un projet en phase d’étude, sans paiement ni service d’envoi configuré

## Points à compléter

- Ajouter le CSS pour le design et l’accessibilité
- Mettre en place un envoi réel des formulaires
- Remplacer les placeholders légaux avant publication
- Vérifier la page de politique de confidentialité avant mise en ligne
- Vérifier que Netlify Forms est correctement configuré après le premier déploiement, car la réception réelle des demandes ne peut pas être testée complètement depuis 127.0.0.1.
- Prévoir une version favicon / logo

## Notes

- Le menu mobile est prévu dans la structure HTML
- Les boutons des offres mènent vers `#contact`
- Les maquettes de démonstration sont indiquées comme fictives
