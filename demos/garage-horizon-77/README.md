Garage Horizon 77 — maquette de démonstration

Prévisualiser localement :

1) Ouvrir un serveur local depuis le dossier `demos/garage-horizon-77` :

```bash
python -m http.server 8000
```

2) Ouvrir http://localhost:8000 dans votre navigateur.

Captures recommandées :
- Desktop : viewport 1366x768
- Mobile : viewport 360x800

Cette démo est statique et n'envoie aucune donnée (formulaire désactivé). Les contenus sont fictifs.
